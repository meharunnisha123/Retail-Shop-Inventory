
# Retail Store Inventory Analysis

This project is a Retail Store Inventory Analysis created using Power BI, SQL, and Python (Pandas). The goal of this project is to analyze inventory data and generate useful business insights.

Using this project, we can:

* Track inventory levels
* Analyze product categories
* Find total revenue
* Compare sales across regions
* Identify low and high stock products
* Create interactive dashboards

Tools Used

* Power BI – Dashboard and visualization
* SQL – Data analysis and queries
* Python (Pandas) – Data cleaning and preprocessing

Project Steps

1. Import dataset
2. Clean data using Pandas
3. Analyze data using SQL
4. Build dashboard in Power BI
5. Generate business insights

Outcome

This project helps retail stores make better decisions by understanding inventory performance and sales trends.
